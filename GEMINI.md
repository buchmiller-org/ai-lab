# AI Assistant Instructions

All project conventions, architecture constraints, and workflows are maintained in [AGENTS.md](AGENTS.md). Please read and adhere to `AGENTS.md`.

## Key Reminders
- **Static Only:** Pure HTML, CSS, JavaScript. No build step or package managers for production files.
- **Paths:** Always use relative paths (`./`, `../`). Never use domain-root absolute paths (`/style.css`).
- **Validation:** Run `python3 scripts/check.py` before finalizing changes.
